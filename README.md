# Supermarket Shopping Challenge

A mobile-friendly supermarket game made with HTML, CSS, and JavaScript.

## Features
- Customer shopping requests
- Touch-friendly product cards
- Score, three lives, timer, and increasing levels
- Hint button and optional sound
- No build tools or installation required

## Play locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `Supermarket-Shopping-Challenge`.
2. Open the repository and choose **Add file → Upload files**.
3. Upload `index.html` (you can also upload this README).
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**.
6. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
7. Wait a few minutes and open:
   `https://YOUR-GITHUB-USERNAME.github.io/Supermarket-Shopping-Challenge/`

This version is a 2D illustrated game, not a true 3D/VR game. It is designed to work reliably on phones first. VR support can be added as a separate upgrade.
